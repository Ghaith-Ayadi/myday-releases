# MyDay releases

This repository only holds signed MyDay builds for testers. The source code is private and lives elsewhere.

- Download the latest build from [Releases](https://github.com/Ghaith-Ayadi/myday-releases/releases/latest) (the `.dmg`), open it and drag MyDay to Applications.
- Installed copies update themselves from `latest.json` on the latest release, and back up their data before every update.
- Every build is code signed with the same identity and every update is signed with the MyDay updater key, so an update from anywhere else is refused.
